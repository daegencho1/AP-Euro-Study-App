# AP European History Study App

A full-stack web app for AP Euro exam prep, built with React, Tailwind CSS, 
and Express. Features an AI tutor powered by the Anthropic Claude API.

## Live Demo
https://ap-euro-study-app-ie8v.onrender.com

## Features
- Flashcard review across all 9 AP Euro units
- Multiple-choice practice questions
- Vocabulary search
- AI tutor chatbot
- SAQ/LEQ essay prompt generation

## Tech Stack
- Frontend: React, Tailwind CSS
- Backend: Node.js, Express
- AI: Anthropic Claude API

## Running Locally
1. Clone the repo
2. Run `npm install`
3. Add your Anthropic API key to a `.env` file as `REACT_APP_ANTHROPIC_KEY`
4. Run `npm run dev` to start both the frontend and backend
